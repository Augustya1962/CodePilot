# CodePilot SEO Mini-Project — Working Notes

## Project concept
**Name:** CodePilot — Coding & Placement Prep  
**Purpose:** Help college students organise programming fundamentals, DSA, SQL/DBMS revision, and technical interview preparation into manageable learning paths.  
**Primary audience:** College students and beginner programmers preparing for internships or entry-level technical placements.  
**Differentiator:** A calm, step-by-step learning hub with topic checklists, short examples, and interview preparation prompts rather than a generic list of links.

### Research process to document
1. Use Google autocomplete and related searches for each seed keyword.
2. Use Google Trends to compare interest over time where data exists.
3. Use Keyword Planner or another available keyword tool to record volume range, location, and date checked.
4. Search each query in a clean/private browser window and record the top relevant results, page formats, and common subtopics.
5. Identify a realistic content gap: clearer beginner sequencing, examples, and a focused placement context. Do not claim a gap until competitor pages have actually been reviewed.
6. Keep a screenshot or dated evidence of your research and cite sources in the report.

## On-page SEO implemented in starter site
- Unique page title and meta description on each page
- Responsive layout and semantic page sections
- Descriptive internal links and clear page hierarchy
- Canonical URL placeholder on each page
- Homepage WebSite JSON-LD structured data
- `robots.txt` and `sitemap.xml` placeholders
- Mobile navigation and small client-side learning interactions

## SEO tasks after publishing
1. Replace all `YOUR-SITE-NAME.pages.dev` placeholders with the actual domain.
2. Check HTTP status and that all page assets load.
3. Test metadata, headings, internal links, keyboard navigation, and mobile display.
4. Run Lighthouse/PageSpeed Insights and record actual results with date/device conditions.
5. Verify site in Google Search Console and submit sitemap.
6. Use URL Inspection to request indexing if appropriate; do not imply submission guarantees indexing.
7. After time has passed, document Search Console impressions/clicks/queries if available.
