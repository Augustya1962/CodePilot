YOUR FIRST CONCEPTS

Build the basics, properly.

01

Variables & data types

A variable is a name that refers to a value. Python determines the type from the value you assign.

name = "Aarav"
semester = 7
ready_to_learn = True

print(name, semester)

Try it: change the name and print a different message.

02

Conditions

Use if, elif, and else to make a decision based on a condition.

score = 72

if score >= 60:
    print("Keep going")
else:
    print("Review and retry")

Try it: test what happens when score is 59.

03

Loops

Loops repeat a block of code. A for loop is useful when iterating over a sequence.

for number in range(1, 4):
    print("Practice", number)

Try it: print numbers from 1 to 10.

04

Functions

Functions package a reusable task. Parameters let you provide different inputs.

def greet(name):
    return f"Hello, {name}!"

print(greet("learner"))

Try it: write a function that returns the square of a number.
