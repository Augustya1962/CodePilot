SQL helps you retrieve and organise data. DBMS concepts help you understand how that data is structured, protected, and managed.

SQL QUICK REFERENCE

Start with the queries you use most.

TaskExample queryWhat it does
Select rowsSELECT name FROM students;Returns the name column.
Filter resultsSELECT * FROM students WHERE age >= 20;Keeps rows matching a condition.
Sort resultsSELECT * FROM students ORDER BY name;Orders the output alphabetically.
Group recordsSELECT city, COUNT(*) FROM students GROUP BY city;Counts students in each city.
Join tablesSELECT s.name, e.course FROM students s JOIN enrollments e ON s.id = e.student_id;Combines matching rows across tables.
DBMS CONCEPT

Primary key

A column or set of columns that uniquely identifies each row in a table. It must be unique and cannot be NULL.

DBMS CONCEPT

Foreign key

A constraint that links a column to a key in another table, helping maintain referential integrity.

DBMS CONCEPT

Normalization

A way to organise relational tables to reduce avoidable duplication and update anomalies.
